---

The ChSON CLI validates files against the schema and renders them to Markdown.

## Installation

The CLI is included in the monorepo. From the repository root:

```bash
npm install
```

## Validate a Cheatsheet

```bash
node packages/chson-cli/src/chson.js validate path/to/file.chson.json
```

Validates against the ChSON schema.

### Validate All Cheatsheets

```bash
npm run validate
```

This validates all cheatsheets in `packages/chson-registry/cheatsheets/`.

## Render to Markdown

```bash
node packages/chson-cli/src/chson.js render markdown path/to/file.chson.json
```

Outputs a 2-column Markdown table using the cheatsheet's column labels (`anchorLabel` and `contentLabel`).

### Example Output

For a cheatsheet with `anchorLabel: "Shortcut"` and `contentLabel: "Action"`:

```markdown
## Navigation

| Shortcut   | Action        |
| ---------- | ------------- |
| `ctrl + n` | Next item     |
| `ctrl + p` | Previous item |
```

## Build All Rendered Output

```bash
npm run render:build
```

Renders all registry cheatsheets to the `build/` directory.

## Schema Validation

The CLI validates against the ChSON schema at `https://chson.dev/api/schema.json`.

## Scaffold a shadcn Registry

You can generate a shadcn-compatible registry source tree from `.chson.json` files:

```bash
node packages/chson-cli/src/chson.js registry init packages/chson-registry/cheatsheets --out examples/chson-shadcn-registry --namespace @chson --homepage https://chson.dev --packs by-directory
```

This generates `registry.json` and `registry/default/**` files that can be built with `shadcn build`.

Defaults:

- target base directory: `chson-files` (`~/chson-files/...` when installed)
- namespace: `@chson`
- packs mode: `none` (optional `by-directory` generates `registryDependencies` pack items)

Optional flags:

- `--packs by-directory` creates installable pack items per directory (for example `git-pack`)
- `--fail-on-collision` exits when two paths map to the same item slug instead of auto-suffixing (`-2`, `-3`)

See [Registries](/docs/registries) for the full publisher and consumer workflow.
