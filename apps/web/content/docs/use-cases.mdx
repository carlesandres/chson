title: Use Cases
description: The kinds of software cheatsheets ChSON is designed for.
---

ChSON describes software cheatsheets. Every kind below uses the same shape: users scan for an **anchor** they recognize to retrieve the **content** they need. What changes is what the anchor and content hold, and which direction users look things up.

## Commands and shortcuts

Quick reference for CLI commands or keyboard shortcuts.

- **anchor**: Command or key combination
- **content**: What it does

```json title="Command cheatsheet excerpt"
{
  "title": "Git Basics",
  "anchorLabel": "Command",
  "contentLabel": "Description",
  "sections": [{
    "title": "Staging",
    "entries": [
      { "anchor": "git add -p", "content": "Interactively stage hunks" }
    ]
  }]
}
```

## Reference tables

Status codes, config keys, syntax and API members: anything users look up by name.

- **anchor**: Code, key, syntax or member name
- **content**: Meaning or effect

```json title="Reference cheatsheet excerpt"
{
  "title": "HTTP Status Codes",
  "anchorLabel": "Code",
  "contentLabel": "Meaning",
  "sections": [{
    "title": "Success",
    "entries": [
      { "anchor": "200 OK", "content": "Request succeeded" },
      { "anchor": "201 Created", "content": "Resource created successfully" }
    ]
  }]
}
```

## Task lookups

When users know what they want to do but not how, flip the direction with `"retrievalDirection": "intent-to-mechanism"`.

- **anchor**: The goal, phrased the way users think of it
- **content**: The command or shortcut that achieves it

```json title="Intent-first cheatsheet excerpt"
{
  "title": "Vim Editing",
  "retrievalDirection": "intent-to-mechanism",
  "anchorLabel": "Task",
  "contentLabel": "Keys",
  "sections": [{
    "title": "Editing",
    "entries": [
      { "anchor": "Delete the current line", "content": "dd" }
    ]
  }]
}
```

## Summary

| Kind                   | Anchor is...               | Content is...       |
|------------------------|----------------------------|---------------------|
| Commands and shortcuts | Command or key combination | What it does        |
| Reference tables       | Code, key or name          | Meaning or effect   |
| Task lookups           | Goal                       | Command or shortcut |

In every kind, optional `details` sit behind a **More** control (a popover in `@chson/ui`), off the primary scan path.
