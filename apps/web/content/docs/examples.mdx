## Key Features Demonstrated

1. **Schema reference** — `$schema` enables IDE validation and autocompletion
2. **Top-level fields** — `homepage` and `tags` for discoverability
3. **Custom column labels** — `anchorLabel: "Shortcut"` and `contentLabel: "Action"`
4. **Retrieval direction** — `mechanism-to-meaning` for command-first lookup
5. **Section descriptions** — Vim Mode section has additional context
6. **Details field** — Extended explanation for complex entries
7. **URL field** — Links to official documentation
